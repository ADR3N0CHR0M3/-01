LibrarySystem

Описание проекта

Консольная система управления городской библиотекой, разработанная на языке C#.

Структура проекта

LibraryApp — консольное приложение для демонстрации работы библиотеки.

LibraryLib — библиотека классов с основными функциями управления.

Реализованные возможности

Получение названия библиотеки.

Изменение названия библиотеки.

Получение и изменение ФИО главного библиотекаря.

Просмотр списка сотрудников.

Добавление и удаление сотрудников.

Поиск сотрудников.

Генерация уникального кода книги.

Обработка ошибок с помощью исключений.

Технологии

C#

.NET 10

Visual Studio
